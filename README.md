# 🏥 DoctorClinic Management System

## 📌 Overview

DoctorClinic is a full-stack web application for managing doctors and patient appointments.

It allows administrators to:

- Manage doctors (Create, Read, Update, Delete)
- Manage appointments
- View dashboard statistics
- Search doctors and appointments
- Login through an admin panel

---

## 🚀 Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- FastAPI
- SQLAlchemy
- Pydantic

### Database
- SQLite

## ✨ Features

- Admin Login

- Search Functionality
- Dashboard Charts
- Form Validation
- Responsive Design

---

## ▶️ How to Run

1. Install dependencies:

```bash
pip install fastapi uvicorn sqlalchemy pydantic
```

2. Start the backend:

```bash
uvicorn backend.main:app --reload
```

3. Open the frontend using your local web server or browser.
